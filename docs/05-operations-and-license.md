# 05 · 운영과 라이선스

> **운영 형태:** 대학이 주관하는 **독립 특강·워크숍**. 금융회사 실무자가 **학교 강의실(전산실)** 에서 수강합니다.
> 이 형태는 라이선스와 설치 환경 양쪽에서 사내 교육보다 **조건이 훨씬 유리합니다.** 대신 학교 전산실 고유의 리스크가 하나 있습니다(2.1).

## 2. 교육 환경 및 기술 요건

### 2.1 ⚠ 학교 전산실 복원 솔루션 — 이 형태의 최대 리스크

대부분의 대학 전산실은 **Deep Freeze 등 복원 솔루션**을 운영해 **재부팅 시 디스크가 초기 상태로 되돌아갑니다.** 2회 분할 과정에서 이는 두 가지 문제를 일으킵니다.

| 문제 | 결과 |
|---|---|
| **설치가 날아감** | D-7에 설치해도 재부팅 한 번이면 사라집니다 |
| **1일차 산출물이 사라짐** | 수강생이 저장한 `M1_이름.alp` 가 2일차에 없습니다 |

#### 대응

| # | 조치 | 비고 |
|---|---|---|
| **1** | 전산 담당 부서에 **복원 대상에서 제외(마스터 이미지에 포함)** 요청 | D-21에 요청. **가장 확실한 해결** |
| **2** | 개인 저장은 **USB 또는 학교 네트워크 드라이브**로 안내 | 로컬 `C:` 저장 금지를 교실에 게시 |
| **3** | 각 회차 시작 시 **파일 일괄 재배포** | 이미 [강제 동기화 규칙](04-labs-and-materials.md#31-모델-파일-10종)으로 운영되므로 추가 부담 없음 |

> **설계가 이 리스크를 이미 흡수하고 있습니다.** 2일차는 `M3_start.alp` 라는 **새 파일에서 시작**하도록 설계되어 있어, 1일차 파일이 사라져도 **학습 진행에는 지장이 없습니다.** 잃는 것은 수강생 개인의 기념 산출물뿐이며, 그것도 조치 2로 해결됩니다.

### 2.2 그 밖의 전산실 확인 사항

| 항목 | 확인 | 미충족 시 |
|---|---|---|
| **설치 권한** | 학생용 계정으로 AnyLogic 실행이 되는가 (설치가 아닌 **실행** 권한) | 관리자 계정 임시 부여 또는 마스터 이미지 반영 |
| **학교 방화벽** | PLE **라이선스 활성화 통신**이 차단되지 않는가 | D-7 설치 시점에 확인. 오프라인 활성화 가능 여부는 [07 · A5](07-ple-verification.md#3-함께-확인할-항목) |
| **저장 공간** | 개인 작업 파일을 저장할 경로가 있는가 | USB 배포로 대체 |
| **공용 계정** | 여러 수강생이 같은 계정을 쓰면 파일이 섞이지 않는가 | 파일명에 **본인 이름 필수** 규칙 |

### 2.3 PC 사양

| 항목 | 최소 | 권장 |
|---|---|---|
| OS | Windows 10 64-bit | Windows 11 |
| RAM | 8 GB | **16 GB** |
| 디스크 여유 | 5 GB | 10 GB |
| 해상도 | 1920×1080 | 1920×1080 이상 |
| Java | AnyLogic 내장 JVM 사용 | — |

> 학교 전산실 PC는 대체로 사양이 균일해 **랩톱 지참보다 유리합니다.** 다만 노후 전산실이라면 D-5 현장 점검에서 **실제 모델 실행 속도를 반드시 실측**하십시오. 모든 템플릿은 애니메이션 비활성화를 기본값으로 고정하고, 실행은 "가상 시간(최대 속도)"으로 설정합니다.

### 2.4 수강생 사전과제 — 설치에서 설문으로

전산실을 쓰면 **설치 사전과제가 불필요해집니다.** 대신 D-3에 짧은 사전 설문을 보냅니다.

- 소속 업무 영역 (창구·채널·리스크·기획 중)
- 업무에서 **"값이 매번 달라져서 곤란한 것"** 1가지
- 엑셀 사용 수준 (자가평가)

이 응답은 **오프닝 사례와 적용 워크숍을 수강생 업무에 맞춰 조정하는 재료**가 됩니다. 사내 교육에서는 설치 과제에 밀려 하지 못하는 일입니다.

## 3. 소프트웨어 라이선스 정책

### 3.1 PLE가 이 과정에 적합한 라이선스입니다

AnyLogic PLE 라이선스 조항은 다음과 같습니다.

> **"teaching or self-education purposes only"** — 교육 또는 자기학습 목적에 한함.
> 그 외의 목적, **상업적 목적 및 연구(research) 목적** 사용은 엄격히 금지.

**대학이 주관하는 교육 과정은 이 조항이 명시적으로 허용하는 용도(teaching)에 해당합니다.** 사내 교육이었다면 "영리 기업 대상 유상 교육이 classroom instruction인가"라는 해석 쟁점이 남았겠지만, **학교에서 진행하는 교육에서는 그 쟁점이 발생하지 않습니다.**

### 3.2 학교이기 때문에 오히려 주의할 점 — 연구 사용 금지

PLE는 **연구(research) 목적 사용을 별도로 금지**합니다. 학교 환경에서는 다음이 실제로 일어날 수 있으므로 사전에 차단하십시오.

- ❌ 조교(대학원생)가 교육용 모델을 **본인 연구에 전용**
- ❌ 전산실 PLE를 **연구실 프로젝트에 사용**
- ❌ 교육 산출물을 **논문·학회 발표 자료로 재사용**

> 연구 목적에는 **University Researcher** 라이선스가 필요하며, 이는 **무료가 아닙니다**(약 $3,550~4,250). 다만 이 라이선스는 **공개 연구 전용**이라 교육용으로는 오히려 부적합하므로, **수업은 PLE, 연구는 별도 라이선스**로 분리하는 것이 맞습니다.

### 3.3 기술 제한 (라이선스 종류와 무관하게 유지)

| 항목 | 한도 |
|---|---|
| 에이전트 타입 | 10 |
| 에이전트당 블록·population | 200 |
| 시스템 다이내믹스 변수 | 200 |
| 동적 생성 에이전트 | 50,000 |
| 모델 시간 (1회 실행) | **5시간** — Process Modeling Library 사용 모델은 예외 |
| OptQuest 최적화 | 변수 7개 / 500 iteration |

> **라이선스 쟁점이 해소돼도 기술 제약은 그대로입니다.** 착수 전 [T1~T4 검증](07-ple-verification.md)은 여전히 필수입니다.

본 과정의 모든 실습은 이 한도 안에 충분한 여유를 두고 설계되어 있습니다 → [03 · 6절 대조표](03-running-case.md#6-ple-기술-제한-대조표)

### 3.4 수강생의 사내 전용 경로

수강생이 교육 산출물이나 동일 도구를 **소속 회사 업무에 적용하려면 별도 라이선스가 필요합니다.** 이것은 학교에서 배웠다는 사실과 무관합니다.

| 경로 | 비용 | 적합한 경우 | 제약 |
|---|---|---|---|
| **PLE 유지** | 무료 | **개인 학습 지속만** | 업무 사용 불가 |
| **30일 평가판** | 무료 | 교육 직후 **사내 PoC 1건** 검증 | 30일 후 만료 |
| **Professional** | 유료 | 실제 업무 도입 확정 시 | 도입 결정 전 선투자 |

> **권장 경로:** 학교 특강(PLE) → **30일 평가판으로 사내 PoC 1건** → 효과 확인 후 Professional 도입 판단 → [06 · 후속 학습 경로](06-assessment-and-followup.md#6-후속-학습-경로)

### 3.5 수강생 고지 문구 (마무리 세션에서 구두로도)

> 오늘 만든 모델은 **교육용 미검증 모델**입니다. 검증(validation)과 보정(calibration)을 거치지 않았으므로 **규제 보고나 실제 의사결정에 직접 사용해서는 안 됩니다.**
>
> 또한 이 과정에서 쓴 PLE는 **교육·자기학습 목적에 한정**되며 상업적 사용과 연구 사용이 금지됩니다. 회사 업무에 적용하시려면 별도 라이선스가 필요합니다.

## 4. 인력 편성과 진행 규율

### 4.1 인력

| 역할 | 인원 (16명 기준) | 책임 |
|---|---|---|
| 강사 | 1 | 전원 대상 진행만 담당. **개인 디버깅은 하지 않음** |
| 조교 (**대학원생 TA**) | **2** | 개별 복구 전담. **조교 1인당 수강생 6~8명** |

> 학교에서 진행하는 이점 중 하나가 **조교 확보가 쉽다는 것**입니다. 다만 TA는 사전에 **전 실습을 직접 완주**해야 하며, 리허설에 반드시 참석시키십시오. 모델을 처음 보는 TA는 도움이 되지 않습니다.
>
> 이 비율이 확보되지 않으면 **5시간 안에 이 커리큘럼은 완주 불가능**합니다.

**2인 1조 페어 실습을 권장합니다.** 완전 초보자 집단에서 페어링은 실패율을 절반으로 낮추고 복구 속도를 두 배로 만듭니다.

### 4.2 진행 규율

| 장치 | 운영 |
|---|---|
| **신호등 카드** | 노트북/모니터에 초록·빨강 포스트잇. 막히면 빨강을 세움 — **손 들기보다 심리적 장벽이 낮고**, 조교가 교실을 훑어 즉시 파악 |
| **체크포인트 저장** | 각 CP마다 `이름_CP3.alp` 로 **USB 또는 네트워크 드라이브에** 저장 (로컬 `C:` 금지 — 2.1) |
| **강제 동기화** | 실습 종료 시 **"전원 `Mx_done`을 여세요"** 선언 → 지연의 누적 전파 차단 |
| **카운트다운 타이머** | 각 실습에 화면 표시 |
| **금지 규칙 3개** | ① 실행 중 편집 금지 ② `Ctrl+Z` 연타 금지 ③ **로컬 디스크에 저장 금지** — 교실에 게시 |

| **R12** | 수강생이 회사 일정으로 2일차 불참 | 중 | 중 | 2일차가 독립 파일로 시작하므로 **1일차 결석자도 합류 가능**. 스크린캐스트로 보충 |
