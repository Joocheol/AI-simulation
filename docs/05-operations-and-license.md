# 05 · 운영과 라이선스

> 이 문서의 2·3절은 **교육 설계보다 상위의 실행 가능성 문제**를 다룹니다. 해소되지 않으면 어떤 시간표도 의미가 없으므로, 계약 검토 단계에서 먼저 확인하십시오.

## 2. 교육 환경 및 기술 요건

### 2.1 ⚠ 망분리(網分離) 환경 — 국내 금융권 최대 리스크

국내 은행 내부망 PC는 통상 다음이 금지됩니다.

- 외부 소프트웨어 설치
- 인터넷 접속
- USB 등 외부 저장매체 사용

그런데 **AnyLogic PLE는 온라인 라이선스 활성화가 필요합니다.** 따라서 *"수강생이 업무용 노트북을 지참해 설치한다"* 는 계획은 **대부분의 은행에서 성립하지 않습니다.**

#### 대응 (계약 조건에 명시)

| 방안 | 내용 | 비고 |
|---|---|---|
| **A (권장)** | **외부망 교육장 PC를 강사 측이 사전 이미징**하여 제공 | 가장 확실. 전원 동일 환경이라 진도 관리도 쉬움 |
| B | 외부망 전용 노트북 대여 (인원수 + **예비 2대**) | 비용 발생 |
| C | 발주사 외부망 교육장 사용 + 사전 설치 협조 | 발주사 IT 부서 협조 필수, D-7까지 완료 |

**파일 배포 경로도 이중화**하십시오 — **USB + 교육장 로컬 공유폴더**. 클라우드 드라이브(Google Drive, Dropbox 등)는 금융권 PC에서 차단되는 경우가 많습니다.

### 2.2 PC 사양

| 항목 | 최소 | 권장 |
|---|---|---|
| OS | Windows 10 64-bit | Windows 11 |
| RAM | 8 GB | **16 GB** |
| 디스크 여유 | 5 GB | 10 GB |
| 해상도 | 1920×1080 | 1920×1080 이상 |
| Java | AnyLogic 내장 JVM 사용 | — |

> **실질적 제약은 PLE 한도가 아니라 랩톱 성능입니다.** 노후 업무용 PC에서는 애니메이션이 켜져 있기만 해도 실행이 수십 초 걸립니다. **모든 템플릿에서 애니메이션 비활성화를 기본값으로 고정**하고, 실행은 "가상 시간(최대 속도)"으로 설정하십시오.

### 2.3 교육장

| 항목 | 요건 |
|---|---|
| 좌석 | **1인 1PC**, 2인 1조 페어 배치 |
| 투사 | **2화면 권장** — 좌: 강사 실시간 조작 / 우: **현재 단계 체크리스트 정지 화면** |
| 강사 화면 | 배율 **125~150% 고정** + 확대 도구 (AnyLogic UI는 글자가 작습니다) |
| 기타 | 화이트보드, 포스트잇(신호등용), 전원 콘센트 |

## 3. 소프트웨어 라이선스 정책

### 3.1 PLE의 제약

AnyLogic **Personal Learning Edition**은 무료이지만 사용 목적이 한정됩니다.

> **"classroom instruction and personal learning"** 목적에 한정되며, **상업적 사용을 금지**합니다.

**기술 제한**

| 항목 | 한도 |
|---|---|
| 에이전트 타입 | 10 |
| 에이전트당 블록·population | 200 |
| 시스템 다이내믹스 변수 | 200 |
| 동적 생성 에이전트 | 50,000 |
| 모델 시간 (1회 실행) | **5시간** — Process Modeling Library 사용 모델은 예외 |
| OptQuest 최적화 | 변수 7개 / 500 iteration |

본 과정의 모든 실습은 이 한도 안에 **충분한 여유를 두고** 설계되어 있습니다 → [03 · 6절 대조표](03-running-case.md#6-ple-기술-제한-대조표)

### 3.2 ⚠ 해소해야 할 쟁점

> **영리 금융회사 임직원 대상 유상 사내교육이 "classroom instruction"에 해당하는가?**

이는 **다툼의 여지가 있는 지점**이며, 발주사 법무·구매 부서가 계약 검토 단계에서 반드시 짚습니다.

#### 조치 (착수 전 필수)

1. **AnyLogic 본사 또는 국내 총판에 서면 확인**을 받으십시오.
2. 동시에 **교육용 임시 라이선스(Training / Evaluation) 견적**을 확보해 두십시오.
3. 확인 결과를 본 문서에 **근거로 명시**하십시오.

### 3.3 교육 후 사내 활용 경로 비교

수강생이 교육 산출물이나 동일 도구를 **실제 업무에 전용하려면 별도 라이선스가 필요합니다.** 발주사가 선택할 수 있도록 세 경로를 제시합니다.

| 경로 | 비용 | 기능 | 적합한 경우 | 리스크 |
|---|---|---|---|---|
| **PLE 유지** | 무료 | 제한 있음 | 개인 학습 지속만 | **업무 사용 불가** — 실무 전용 시 라이선스 위반 |
| **30일 평가판** | 무료 | 전 기능 | 교육 직후 **사내 PoC 1건** 검증 | 30일 후 만료. 연장 불가 |
| **Professional** | 유료 | 전 기능 | 실제 업무 도입 확정 시 | 도입 결정 전 선투자 부담 |

> **권장 경로:** 교육(PLE) → **30일 평가판으로 사내 PoC 1건** → 효과 확인 후 Professional 도입 판단.
> 이 경로를 후속 과정 로드맵과 연계하면 교육이 일회성으로 끝나지 않습니다 → [06 · 후속 학습 경로](06-assessment-and-followup.md#6-후속-학습-경로)

### 3.4 수강생 고지 문구 (마무리 세션에서 구두로도)

> 본 교육에서 만든 모델은 **교육용 미검증 모델**입니다. 검증(validation)과 보정(calibration)을 거치지 않았으므로 **규제 보고나 실제 의사결정에 직접 사용해서는 안 됩니다.**
> 또한 PLE는 상업적 사용이 금지되므로, 사내 업무에 적용하려면 별도 라이선스가 필요합니다.

## 4. 인력 편성과 진행 규율

### 4.1 인력

| 역할 | 인원 (16명 기준) | 책임 |
|---|---|---|
| 강사 | 1 | 전원 대상 진행만 담당. **개인 디버깅은 하지 않음** |
| 조교 | **2** | 개별 복구 전담. **조교 1인당 수강생 6~8명** |

> 이 비율이 확보되지 않으면 **5시간 안에 이 커리큘럼은 완주 불가능**합니다. 발주사에 명확히 전달하는 편이 낫습니다.

**2인 1조 페어 실습을 권장합니다.** 완전 초보자 집단에서 페어링은 실패율을 절반으로 낮추고 복구 속도를 두 배로 만듭니다.

### 4.2 진행 규율

| 장치 | 운영 |
|---|---|
| **신호등 카드** | 노트북 뚜껑에 초록/빨강 포스트잇. 막히면 빨강을 세움 — **손 들기보다 심리적 장벽이 낮고**, 조교가 교실을 훑어 즉시 파악 |
| **체크포인트 저장** | 각 CP마다 `이름_CP3.alp` 로 저장 → 개인 롤백 지점 확보 |
| **강제 동기화** | 실습 종료 시 **"전원 `Mx_done`을 여세요"** 선언 → 지연의 누적 전파 차단 |
| **카운트다운 타이머** | 각 실습에 화면 표시 |
| **금지 규칙 3개** | ① 실행 중 편집 금지 ② `Ctrl+Z` 연타 금지 ③ 체크포인트마다 이름 붙여 저장 — 교실에 게시 |

### 4.3 Go / No-Go 분기점

강사 런북에 명문화합니다 → [02 · 4절](02-schedule.md#4-사전-정의-분기점-go--no-go)
