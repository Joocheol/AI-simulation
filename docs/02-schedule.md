# 02 · 상세 시간표

## 1. 설계 원칙

### 1.1 실습 시간은 "최속"이 아니라 "현실"로 잡는다

초보자 집단의 실측 소요는 숙련자 기준의 **1.6~1.8배**입니다. 첫 모델 제작을 예로 분해하면:

| 작업 | 최속 | 현실 (초보 12~16인) |
|---|---|---|
| 실행·새 모델 생성·시간단위 설정 | 3분 | **6~8분** |
| UI 투어 (Projects/Palette/Properties/캔버스/실행) | 10분 | **15분** |
| 파라미터 3 + 변수 1 + 이벤트 1 + 분포식 | 10분 | **15~18분** |
| 차트 추가 + 데이터 연결 | 5분 | **8분** |
| 첫 실행 + 결과 해석 | 4분 | **7분** |
| **합계** | **32분** | **51~56분** |

그대로 두면 40분 슬롯에서 **15분이 밀리고**, 밀린 15분은 가장 중요한 학습목표(몬테카를로)를 잡아먹습니다.

### 1.2 그래서 세 가지를 바꾼다

| 조치 | 절감 | 근거 |
|---|---|---|
| **스타터 파일 제공** (`M1_start.alp` — 모델 생성·시간단위·프레임·차트 자리 사전 배치) | **8~10분** | 동시에 전원 화면이 같아져 진도 편차의 최대 원인이 제거됩니다 |
| **별도 UI 투어 폐지, "따라하기"로 통합** | **10분** | 별도 투어는 초보자에게 거의 기억되지 않습니다. 손동작 안에서 패널 이름을 그때그때 부르는 편이 정착률이 훨씬 높습니다 |
| **사전 분포 강의 → 치트시트 + 적시 교수** | **10분** | 써본 적 없는 분포를 카탈로그로 훑는 것은 가장 낭비가 큰 시간입니다. 실제로 분포를 고르는 그 순간에 3분만 설명합니다 |

절감 합계 **28~30분**. 51~56분 − 28~30분 ≒ **21~28분** → 40분 슬롯에 **10분 이상 여유**를 두고 들어옵니다.

> 여유분은 의도적입니다. 초보자 실습에서 예상 밖 지연은 **반드시** 발생하므로, 슬롯을 꽉 채워 설계하면 그 순간 뒤가 무너집니다.

### 1.3 휴식은 "블록이 끝나는 곳"이 아니라 "집중력이 끊기는 곳"에

90분 이상 연속 실습은 집중력·요통·화장실 모두에서 파탄입니다. 양일 모두 **연속 구간이 85분을 넘지 않도록** 휴식과 3분 기립 스트레칭을 배치했습니다.

### 2.1 실습2에 대한 중요한 설계 결정

> **몬테카를로 실험 자체를 학습자가 만들게 하지 마십시오.**

출력 수집(Dataset/Output 객체) 설정은 초보자에게 **30분짜리 벽**입니다. 이 세션의 진짜 학습 목표는 **"복제 횟수를 늘리면 히스토그램이 안정된다는 것을 눈으로 보는 것"** 이고, 그건 사전 제작된 실험에서 숫자만 바꾸면 **10분**에 달성됩니다.

남는 20분은 **결과 해석**에 씁니다 — 꼬리, 신뢰구간, 그리고 이 과정에서 가장 중요한 한 문장:

> *"평균으로 보면 안전한데, 5% 확률로 파산합니다."*

### 2.2 1일차 과제 (가볍게)

기업 교육의 과제 수행률은 통상 50% 내외입니다. **무겁게 내면 2일차 도입이 무너집니다.**

- 3문항 자가점검 (객관식)
- 본인 업무에서 **"값이 매번 달라지는 것" 3가지** 적어오기
- 1일차 저장 파일 한 번 열어보기

### 3.1 실습5를 사수하십시오

실습5는 **도구 학습이 아니라 통찰 학습**이며, **위탁 기업이** *"그래서 우리 업무에 뭐가 도움 되나"* 를 판단하는 구간입니다. 가장 가치가 높은데 시간표상 가장 압박받는 위치에 있습니다.

> **강사 런북 규칙: 진도가 밀리면 실습4의 범위를 줄이고 실습5는 사수한다.**

### 3.2 적용 워크숍은 백지로 열지 않습니다

백지 캔버스 + 자유 공유는 15분에 불가능합니다. **완성 예시 캔버스 1부를 먼저 보여주고, 5칸 구조화 양식**에 채우게 합니다. 소프트웨어 없이 끝나는 마무리라 착지가 좋으므로 **순서는 유지**하십시오.

캔버스 5칸: ① 문제 정의 ② 불확실성 요소 ③ 성과지표(KPI) ④ 의사결정 변수 ⑤ 기대 효과

## 4. 사전 정의 분기점 (Go / No-Go)

라이브 실습의 실패는 대부분 "누가 못 따라와서"가 아니라 **"밀렸을 때의 판단 기준이 없어서"** 발생합니다. 강사 런북에 아래를 명문화합니다.

| 분기점 | 판단 기준 | **No-Go 시 조치** |
|---|---|---|
| 1일차 t=70분 | CP2(첫 실행) 도달자 **80% 미만** | Parameter Variation 데모 삭제, 실습2를 축소판으로 전환 |
| 2일차 t=80분 | CP7(Statechart) 진입 지연 | 실습4를 **강사 시연 + 완성 파일 배포**로 전환, 절약분을 실습5로 이전 |
| 2일차 t=110분 | 실습5 미착수 | 정책 3안 → **2안으로 축소**. 캔버스는 사수 |

## 5. 분할 운영 대안

기본 설계는 **2.5시간 × 2회**입니다. 위탁 기업 사정이나 학사 일정에 따라 아래로 재배치할 수 있습니다.

### 5.1 하루 5시간 집중

**교육시간 300분 + 휴식·점심 75분 = 총 체류 375분(6시간 15분)**

| 블록 | 교육 | 내용 | 여유 |
|---|---:|---|---:|
| **A** | 75분 | 오프닝 10 · 기초 15 · 환경점검 5 · **실습1** 40 | 5분 |
| — | *15분* | *휴식* | |
| **B** | 65분 | 몬테카를로 개념 15 · **실습2** 30 · PV 데모 8 · 정리 12 | 0분 |
| — | *45분* | ***점심*** | |
| **C** | 55분 | **실습3** 42 | 13분 |
| — | *10분* | *휴식* | |
| **D** | 50분 | **실습4** 37 | 13분 |
| — | *5분* | *스트레칭* | |
| **E** | 55분 | **실습5** 25 · 적용 워크숍 15 · 마무리 5 | 10분 |
| **계** | **300분** | | **41분** |

- 2일차 도입부의 복습 8분·파일 확인 5분은 **불필요하므로 삭제**하고, 그 13분을 블록 C·D의 완충으로 돌렸습니다.
- 여유 41분은 하루 집중 운영에서 **반드시 필요합니다.** 2회 분할과 달리 밀린 시간을 다음 회차로 넘길 수 없습니다.
- **후반 집중력이 최대 리스크**입니다. 점심 이후 블록 C·D·E는 전부 손을 쓰는 활동입니다.

### 5.2 1시간 × 5회

| 회차 | 내용 | 주의 |
|---|---|---|
| 1 | 오프닝 + 기초 3개념 + 실습1 착수 | 실습1이 회차 경계에서 잘립니다 |
| 2 | 실습1 완료 + 몬테카를로 개념 | **도입부 복습 7분 필수** |
| 3 | 실습2 + PV 데모 | 복습 7분 |
| 4 | 실습3 (채널 폭주) | 복습 7분. 1시간이 빠듯합니다 |
| 5 | 실습4 축약 + 실습5 + 캔버스 | **실습4를 강사 시연으로 전환 권장** |

> **권장하지 않습니다.** 매회 환경 재세팅(실행·파일 열기·화면 동기화)에 5~7분이 소모되어 **실효 학습시간이 약 30분(10%) 감소**하고, 실습이 회차 경계에서 잘립니다. 불가피한 경우에만 선택하십시오.
