# 04 · 실습 · 교재 사양

## 1. 실습 설계 원칙

> ### "코드는 저희가 씁니다. 여러분은 구조와 숫자를 바꿉니다."

| 학습자가 하는 일 | 사전 제공되는 것 |
|---|---|
| 블록 드래그 · 연결 | 에이전트 타입, population |
| 상태 · 전이 그리기 | 에이전트–프로세스 결합부 |
| 드롭다운 선택 | 헬퍼 함수 (`불안비율()` 등) |
| **숫자 입력** | 차트, 데이터셋, 실험 설정 |
| 차트 읽기 · 해석 | 캔버스 레이아웃, 뷰, 주석 |

### 1.1 백지에서 시작하지 않습니다

초보자가 40분 안에 첫 모델을 완성하려면 백지 시작은 불가능합니다. 모든 실습은 **캔버스·뷰·주석·차트 자리가 미리 배치된 `Mx_start` 파일**에서 출발하고, 학습자는 **개념적으로 의미 있는 부분만 직접 조립**합니다.

이것은 난이도 하향이 아니라 **학습 시간의 재배분**입니다. 차트 축 설정에 8분을 쓰는 것보다 결과 해석에 8분을 쓰는 편이 학습 가치가 훨씬 높습니다.

## 2. 실습별 "사전 제공 vs 학습자 작업" 대조표

> 이 표는 **위탁 기업의 "우리 직원이 정말 따라갈 수 있나?" 우려에 대한 답변**이자, 모델 제작 단계의 **범위(scope) 정의서**로 기능합니다.

### 실습1 (M1) — 인출액 확률모델 · 40분

| 사전 제공 (`M1_start.alp`) | 학습자 작업 |
|---|---|
| 모델 생성, 시간 단위, Main 프레임 | 파라미터 3개 입력 (`N`, 평시인출률, 위기배수) |
| 히스토그램 객체 + 데이터 연결 | 분포식 1개 작성 — `triangular(50, 800, 5000)` (치트시트 참조) |
| 캔버스 레이아웃 · 한글 주석 | 이벤트 1개 생성 + 액션 연결 |
| 실행 설정 (애니메이션 off) | 실행 → 시드 변경 → 재실행 |

**코드 노출:** 분포식 1줄 — `triangular(50, 800, 5000)`

> ⚠ **`NORM.INV`와 대조하지 마십시오.** 정규분포 함수라 삼각분포의 대조 대상이 아닙니다. `normal()`의 인자 순서 함정은 [치트시트 2절](handouts/distribution-cheatsheet.md#2--반드시-기억할-함정-2개)에서 별도로 다룹니다.

### 실습2 (M2) — 몬테카를로 · 30분

| 사전 제공 (`M2_start.alp`) | 학습자 작업 |
|---|---|
| **Monte Carlo 실험 전체** | 복제 횟수 변경: 1 → 10 → 100 → 1,000 |
| Output 객체, 데이터 수집 | 히스토그램 수렴 **관찰** |
| 결과 히스토그램, 통계 표시 | P(유동성 부족) 산출 → 워크시트 기록 |
| 신뢰구간 표시 | 꼬리 구간 해석 |

**코드 노출:** 없음

### 데모 (Parameter Variation) — 8분 · 강사 전용

학습자는 손을 떼고 관찰만 합니다. 완성 파일 `PV_demo.alp` 만 배포합니다.

### 실습3 (M3) — 채널 폭주 · 42분

| 사전 제공 (`M3_start.alp`) | 학습자 작업 |
|---|---|
| 팔레트 배치, 캔버스 안내선 | `Source → Queue → Service → Sink` **5블록 배치·연결** |
| 파라미터(도착률, 처리시간 분포) | `ResourcePool` 추가 + Service에 연결 |
| 대기열·대기시간 차트 | 창구 수 `c` 입력 |
| 영업시간 Schedule | 평시 실행 → **위기 도착률로 변경 → 재실행** |
| **모든 블록의 시간 단위 드롭다운 사전 고정** | 대기열 발산 관찰 |

**코드 노출:** 없음 (전부 GUI)

### 실습4 (M4) — 예금자 확산 · 37분

| 사전 제공 (`M4_start.alp`) | 학습자 작업 |
|---|---|
| 예금자 에이전트 타입 + population(2,000) | 상태 3개 그리기: `평온 → 불안 → 인출시도` |
| **에이전트–프로세스 결합부** (도착률 함수) | 전이 3개 그리기 |
| 헬퍼 함수 `불안비율()` | 전이 트리거 선택 (드롭다운) |
| 상태별 인원 추이 차트 | `beta * 불안비율()` **따라 입력** |
| 결합계수 슬라이더 | β 조정 (0.3 → 0.9) 후 재실행 |

**코드 노출:** 표현식 1줄 (`beta * 불안비율()`) — 엑셀 수식과 동일한 체감

### 실습5 (M5) — 정책 비교 · 25분

| 사전 제공 (`M5_start.alp`) | 학습자 작업 |
|---|---|
| 정책 스위치 3개 + **시나리오당 20복제 실험(사전 구성)** | 정책 스위치를 바꿔 **6개 시나리오 실행** |
| 위기강도 프리셋 (중/고) | **[비교 워크시트](handouts/scenario-comparison-worksheet.md) 작성** |
| KPI 자동 집계 표시 | 트레이드오프 발견 |
| 비교표 워크시트 (엑셀/종이) | **정책 권고 1줄 작성** |

**코드 노출:** 없음

## 3. 배포 자료 목록

### 3.1 모델 파일 (12종)

모든 실습에 **시작 파일과 완성 파일을 쌍으로** 준비합니다.

| 파일 | 용도 |
|---|---|
| `M1_start.alp` / `M1_done.alp` | 실습1 |
| `M2_start.alp` / `M2_done.alp` | 실습2 |
| `M3_start.alp` / `M3_done.alp` | 실습3 |
| `M4_start.alp` / `M4_done.alp` | 실습4 |
| `M5_start.alp` / `M5_done.alp` | 실습5 |
| `PV_demo.alp` | Parameter Variation 데모 (배포용) |
| `install_test.alp` | **D-7 전산실 일괄 설치 검증용** (강사·전산 담당 사용) |

> 실습용 `start`/`done` 10종 + 보조 2종(`PV_demo`, `install_test`) = **총 12개 파일**.

> **강제 동기화 규칙 (가장 중요한 운영 장치)**
> 각 실습 종료 시점에 강사가 **"지금부터 전원 `Mx_done`을 여세요"** 라고 선언하고 리셋합니다.
> 이것 없이는 개인의 지연이 다음 실습으로 누적 전파되어 **2일차 후반에 절반이 낙오합니다.**

### 3.3 워크북 작성 규칙

구두 설명만으로는 재현되지 않습니다. **클릭 경로를 문자로 적으십시오.**

> ❌ "에이전트를 하나 만듭니다"
> ✅ **`Palette > Agent > [Agent]` 를 캔버스로 드래그 → 이름란에 `Depositor` 입력 → [Finish]**

각 체크포인트마다 **"이 화면이 보이면 성공"** 스크린샷을 함께 배치합니다.

### 3.4 스크린캐스트 (실습당 3~5분)

사전 제작해 배포합니다. 휴식 시간에 낙오자가 따라잡을 수 있고, **교육 후 복습 자산**이 됩니다. 총 5편, 약 20분.

## 4. 제작 일정

| 단계 | 기간 | 산출물 | 선행 조건 |
|---|---|---|---|
| **0. 제약 검증** | 0.5일 | [T1~T4 검증 결과](07-ple-verification.md), **트랙 A/B 확정** | — |
| 1. 설계 문서 승인 | — | 본 문서 세트 확정 | 0 완료 |
| 2. 모델 제작 | 4일 | `M1`~`M5` start/done 10종 | 1 완료 |
| 3. **파일럿 실행** | 1일 | 전 모델 실측 실행, PLE 한도 재확인 | 2 완료 |
| 4. 워크북·슬라이드 | 3일 | 슬라이드 45장, 워크북 30쪽, 치트시트 | 3 완료 |
| 5. 스크린캐스트 | 1일 | 5편 | 4 완료 |
| 6. **리허설** | 0.5일 | 강사 런북 확정, 타임박스 실측 | 5 완료 |
| **계** | **10일** | | |

> **단계 0을 건너뛰지 마십시오.** T2·T4 결과에 따라 모델 시간 축(트랙 A/B)이 달라지고, 트랙 B면 **모든 모델의 시간 단위·차트 축·워크북 환산표를 다시 만들어야 합니다.** 0.5일을 아끼려다 4일을 재작업하게 됩니다.

## 5. 심화 과제 카드

빠른 수강생을 방치하면 앞서 나가 파일을 망가뜨리고 조교 시간을 잡아먹습니다. **실습마다 1장씩** 준비합니다.

| 실습 | 심화 과제 |
|---|---|
| M1 | 인출액 분포를 `lognormal` → `triangular`로 바꾸면 꼬리는 어떻게 달라지나? |
| M2 | 복제 100회를 5번 반복하면 P값이 얼마나 흔들리나? (추정의 불확실성) |
| M3 | 포기 대기시간을 60분 → 30분으로 줄이면 포기 건수와 앱 전환은? |
| M4 | 미디어 충격을 2일차에 한 번 더 주면 곡선이 어떻게 변하나? |
| M5 | P1+P3를 동시에 적용하면 단독 적용의 합보다 나은가? |
