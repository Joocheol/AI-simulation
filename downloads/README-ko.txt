고정 비교 자료
gbm-fixed-seed.csv는 실제 시세가 아닌 합성 GBM입니다. seed=20261002, Python random.Random.gauss를 사용했습니다.
실제 자료에서 얻은 일 로그수익률 평균 m 및 표준편차 s로 r=m+sZ를 생성했습니다.
연 σ=s×sqrt(252), 연 μ=252m+0.5×연σ²로 연결됩니다.
같은 모수라도 유한 표본의 평균·표준편차가 정확히 일치하지 않습니다.
04_고정비교 위쪽 요약은 고정 참조 통계입니다. B12,D12 입력 변경은 아래 합성 경로 수식에만 반영됩니다.
공식과 검증된 참조 통계, 히스토그램 구간, lag1~20 자기상관은 source-and-statistics.json에 있습니다.
KURT는 표본 편향보정 초과첨도입니다. 표준화 z는 각 표본 자신의 평균·표준편차를 사용합니다.
ACF는 전체평균/고정분모 정의 대신 lag별 짝지은 두 부분 표본의 Pearson CORREL입니다.
약 95% 기준선 ±1.96/sqrt(n)은 독립 가정의 설명용 근사이며 다중 lag/비정규성/추정 오차를 반영하지 않습니다.

검증 범위

생성용 계산엔진은 INDEX로 끝점을 정하는 CORREL 범위를 계산하지 못했습니다. ACF 수식은 표준 Excel 문법이며 실제 표본의 고정 범위 CORREL과 별도 수치 계산을 대조했습니다. 실제 CSV를 넣은 뒤 Excel에서 J12:L31이 계산되는지 확인하세요.

Windows Excel 데스크톱에서 직접 실행 검증한 것은 아닙니다. 첫 수업 전에 사용하는 Excel 버전에서 재계산해 확인하세요.
참조기간과 데이터 공급자의 수정에 따라 재다운로드 값은 달라질 수 있습니다. source-and-statistics.json의 조회일을 확인하세요.
