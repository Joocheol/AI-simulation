# Bornholdt 격자 시장: 과학 설명과 구현 안내

## 화면에 사용할 설명

각 칸은 매수(+1) 또는 매도(−1) 성향을 가진 가상 참여자입니다. 상하좌우 이웃을 따르는 힘과, 전체가 한쪽으로 쏠릴수록 현재 선택을 바꾸려는 힘이 경쟁합니다. 격자의 무늬와 전체 수익률을 함께 보며 미시 규칙이 집단 변동으로 이어지는 과정을 살펴봅니다.

Bornholdt(2001)의 순간적 전략 조정 모형, 식 (4)를 사용합니다.

- M = (1/N) Σᵢ sᵢ
- hᵢ = J Σⱼ∈이웃 sⱼ − α sᵢ |M|
- P(sᵢ′=+1) = 1 / [1 + exp(−2βhᵢ)]

J는 이웃 동조, α는 전체 쏠림에 대한 전환 압력, β는 장에 반응하는 정도입니다. β가 작을수록 선택이 더 무작위적입니다. α=0은 전역 경쟁을 끈 이징 모형 대조군입니다. α 효과는 단순히 다수만 반대로 움직이게 하는 고정 규칙이 아닙니다. |M|가 커지면 각 참여자의 현재 상태를 뒤집는 방향으로 작용합니다.

게임 오브 라이프와의 공통점은 간단한 국소 규칙에서 집단 무늬가 생긴다는 점입니다. 차이는 이 모형이 전역 정보 |M|도 이용하고, 무작위 순서·확률적 갱신을 쓴다는 점입니다. 한 스윕은 N번의 갱신 시도입니다. 같은 칸이 여러 번 뽑히거나 한 번도 뽑히지 않을 수 있습니다. 스윕은 실제 하루가 아닙니다.

### 가격은 무엇인가요?

Kaizoji·Bornholdt·Fujiwara(2002), 식 (8)·(10)의 상수 기초가격 가정에 따라 교육용 가격 지수를 구성합니다.

Pₜ = P_f exp(κ Mₜ), rₜ = log(Pₜ/Pₜ₋₁) = κ(Mₜ−Mₜ₋₁).

기본 P_f=100, κ=1이며 κ는 표시 변동 폭의 임의 척도입니다. 원화 가격이나 추정 계수가 아닙니다. 자화 M 자체에 로그를 취하지 않습니다. 기초가치의 외생 뉴스, 주문장, 거래비용, 유동성, 자산·부채 제약을 구현하지 않았습니다.

### 해석 주의

이것은 실제 주가 예측기나 투자 전략 검증기가 아닙니다. 원 논문은 특정 실험에서 큰 변동과 변동성 군집을 보고했지만, 모든 매개변수·시드·짧은 실행에서 관찰된다고 보장할 수 없습니다. 첨도가 3보다 크다는 사실만으로 멱법칙 꼬리가 증명되지 않습니다. 초기 과도기와 작은 표본은 해석을 바꿀 수 있습니다. 여러 시드, 충분한 예열·표본, α=0 대조군을 함께 비교해야 합니다.

## 출처와 참고 사이트 비교

1. Stefan Bornholdt (2001), *Expectation bubbles in a spin model of markets: Intermittency from frustration across scales*. 식 (1), (4), Fig.1의 J=1, α=4, T=1.5를 참고. https://arxiv.org/abs/cond-mat/0105224 ; 원문 https://arxiv.org/pdf/cond-mat/0105224
2. T. Kaizoji, S. Bornholdt, Y. Fujiwara (2002), *Dynamics of price and trading volume in a spin model of stock markets with heterogeneous agents*. 가격 연결 식 (8), (10), §3.1의 J=1, α=20, T=0.5를 참고. 원문의 101×101 대신 교육 프리셋은 64×64이므로 수치 재현을 주장하지 않음. https://arxiv.org/abs/cond-mat/0207253 ; 원문 https://arxiv.org/pdf/cond-mat/0207253
3. Aleksejus Kononovicius, Physics of Risk (2011), 상호작용 시각화 참고: https://rf.mokslasplius.lt/bornholdt-model/

참고 사이트의 단순화된 장 식에는 sᵢ 인자가 빠져 있습니다. 구현에서는 Bornholdt 원문의 식 (4)에 따라 −α sᵢ|M|를 사용했습니다. 이웃 격자와 시계열을 함께 읽는 시각적 아이디어만 참고했으며 사이트의 코드·그림을 복사하지 않았습니다. 파일은 논문의 규칙에 기반하여 새로 작성했습니다.

## ES module API

파일: `abm.js`. 브라우저에서 `import {BornholdtModel, PRESETS, summarizeReturns} from './abm.js'`로 사용합니다. 의존성 없음.

### 생성·재시작

`new BornholdtModel(options={})`: 균등한 독립 ±1 초기 배치. 같은 설정·시드·호출 순서는 같은 경로를 만듭니다.

- `L`: 한 변의 칸 수, 정수 4–256; 기본 32. N=L².
- `J`: 이웃 결합 0–10; 기본 1.
- `alpha`: 전역 전환 결합 0–100; 기본 4.
- `beta`: 역온도 0–20; 기본 1/1.5. 온도 UI는 beta=1/T로 연결.
- `seed`: 정수 0–4294967295; 기본 42. Mulberry32 난수, 암호학적 용도 아님.
- `kappa`: 가격 지수 척도 0–5; 기본 1.
- `fundamental`: 상수 기준가격 0.000001–10⁹; 기본 100.
- `historyLimit`: 보존 스윕 관측 수 정수 0–10⁶; 기본 2000. 0이면 기록 없음.
- `reset(options={})`: 기존 설정과 새 설정을 합쳐, 해당 시드로 초기화하고 초기 관측을 반환. 격자·시간·이력을 모두 초기화.

### 시뮬레이션

- `spins`: 행 우선 Int8Array, 인덱스 y*L+x, 값 ±1. Canvas로 직접 읽되 쓰지 마세요.
- `neighbors`: 각 셀의 좌·우·상·하 인덱스 네 개를 담은 Int32Array. 주기 경계.
- `magnetization`: 현재 M 읽기 전용 getter.
- `price`: 현재 P_f exp(κM) 읽기 전용 getter.
- `time`: 완료 스윕 수. 초기 0.
- `sweep()`: N개 셀을 복원추출하여 순차 갱신. 개별 갱신마다 이웃과 M은 최신 상태. 완료 스윕 관측 반환.
- `step(n=1)`: n 스윕 수행, 마지막 관측만 반환. `n` 정수 1–10⁶. 수익률은 마지막 한 스윕의 수익률이지 n스윕 누적값이 아님.
- `run(n=100)`: n 스윕 관측 배열 반환.
- `last`: 가장 최근 완료 관측.
- `history`: 보존 관측 배열, 초기 t=0 포함. 통계에서 초기 관측의 0 수익률은 제외 권장.
- `localField(i)`: 현재 i번째 셀의 hᵢ.
- `setParameters({J,alpha,beta,kappa})`: 상태를 유지하여 결합 변경. 다른 키는 오류. 비교 실험은 reset을 권장. 특히 κ를 중간 변경하면 표시 가격 척도가 바뀌므로 전후 가격 수익률 비교를 피하고 이력을 초기화하세요.

### 관측 형식

`{time, magnetization, m, price, logReturn, return, absReturn, buyFraction, flips, flipRate}`

- `m`은 magnetization의 별칭, `return`은 logReturn의 별칭.
- `logReturn`: κ ΔM, 퍼센트 아님. 로그수익률 % 표시는 100배. 단순수익률은 exp(logReturn)−1.
- `absReturn`: |κ ΔM|. 변동성 군집을 탐색하는 대용 지표.
- `buyFraction`: (1+M)/2. 자산 보유량·실제 거래량 아님.
- `flips`: 스윕 중 실제 상태가 바뀐 횟수. 서로 다른 참여자 수가 아님.
- `flipRate`: flips/N. 실제 거래량 지표로 이름 붙이지 마세요.

### 추가 내보내기

- `PRESETS.teaching`: L32, J1, α4, β1/1.5.
- `PRESETS.control`: teaching과 같고 α0.
- `PRESETS.paperInspired`: L64, J1, α20, β2. 원문 크기와 다름.
- 모든 프리셋 κ1, P_f100, seed42. 생성 시 `{...PRESETS.control, seed:7}`처럼 사용.
- `seededRandom(seed)`: [0,1) 난수 함수를 반환.
- `heatBathProbability(field,beta)`: 수치 안정적 로지스틱.
- `summarizeReturns(values,lags=[1,5,10,50])`: 표본 수, 평균, 모집단식 표준편차, 모집단 중심적률식 첨도, 초과첨도, |r| ACF 반환. 0분산·부족한 표본의 값은 null. 유의성 검정 아님.
- `MODEL_SOURCES`: 출처 URL 배열.

### UI 권장

파라미터 변경은 일시정지·초기화하여 조건을 명확히 표시하세요. 모델 시간과 화면 재생 속도를 구별하세요. 비교 시 같은 시드를 사용할 수 있으나 경로가 갈라지므로 개별 피크를 직접 인과 비교하지 마세요. 처음에는 낮은 배속으로 격자의 군집을 보고, 이후 빠르게 실행하여 긴 시계열을 얻도록 합니다. 25,000스윕 실험은 UI 스레드 밖 Web Worker 또는 나눈 작업에서 수행하고, 매 스윕을 모두 다시 그리지 않는 편이 좋습니다.

검증 파일 `abm-validation.json`은 결정성·경계·수익률 항등식 단위 점검과 α0/α4/α20의 3개 시드 실험을 담습니다. 재실행: `node validate-abm.mjs`.

## 실제 실행 검증 결과 (2026-10-02)

시드 7·42·2026 각각 5,000스윕 예열 후 25,000스윕을 측정했습니다. 모든 조건은 J=1, κ=1이며 한 스윕 수익률을 사용했습니다. 이 예열 길이가 완전한 정상상태 도달을 보증하지는 않습니다.

| 조건 | 첨도 범위 | 절대수익률 ACF 지연 50 범위 |
|---|---:|---:|
| L32, T1.5, α0 | 3.15–3.34 | −0.006–0.002 |
| L32, T1.5, α4 | 4.04–4.29 | 0.068–0.094 |
| L64, T0.5, α20 | 34.60–45.41 | 0.259–0.315 |

이는 이 실행에서 α4 조건이 비교 대조군보다 큰 첨도·긴 변동성 의존을 보였다는 제한된 결과입니다. 꼬리 지수 추정이나 실제 시장 적합도 검증은 수행하지 않았습니다.

매우 낮은 온도의 추가 대조군 L64, T0.5, α0은 시드에 민감했습니다. 시드 7·42는 준안정 공간 패턴에 머물렀고 첨도 4.18·4.49였습니다. 시드 2026은 거의 완전 정렬 상태여서 표준편차가 약 0.0000107로 작지만 드문 전환 때문에 첨도는 약 2083이었습니다. 따라서 ‘α가 크면 항상 첨도가 크다’, ‘큰 첨도면 현실적 시장이다’라고 해석하면 안 됩니다. 값이 거의 모두 0인 시계열의 첨도는 특히 주의해야 합니다.

단위 점검 통과: 동일 시드 결정성, ±1 상태 불변식, 누적 합과 전체 자화 합의 일치, 주기 경계 이웃, 전체 스핀 반전 대칭, β=0에서 확률 1/2, 안정적 로지스틱, 가격·로그수익률 항등식.
